# Destino Cordillera (Equipo10_solemne1_web)

## Nombre del proyecto

**Destino Cordillera** — sitio web de promoción turística para una comuna ficticia de montaña.

## Integrantes del equipo

- Cristobal Garrido
- Gabriel Moreno
- Brandon Valdes

## Descripción

Sitio web turístico que presenta el destino "Destino Cordillera" con información general, panoramas y actividades, opciones de alojamiento y gastronomía, y un formulario de reserva y contacto. Cuatro páginas navegables con identidad visual coherente: paleta azul/índigo, tipografía Inter y componentes compartidos de tarjetas, botones, navegación y pie de página.

## Cómo ejecutar o visualizar el sitio

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/GGMoreno018/Equipo10_solemne1_web.git
   ```
2. Abrir el archivo `index.html` en un navegador web 


## Páginas

| Archivo | Contenido |
|---|---|
| `index.html` | Inicio: imagen principal, descripción y accesos a las secciones |
| `panoramas.html` | Seis actividades y lugares de interés en tarjetas |
| `alojamiento.html` | Alojamiento y gastronomía en tarjetas informativas |
| `contacto.html` | Formulario de reserva, datos de contacto y ubicación referencial |

## Tecnologías utilizadas

- **HTML5** — estructura semántica (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3** — hoja de estilos propia y externa en `css/estilos.css` (tipografía, colores, espaciados, botones, tarjetas, grid y responsive)
- **Bootstrap 5.3.2** — componentes únicamente en `contacto.html` (formulario y tarjetas)
